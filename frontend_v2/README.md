# Research dashboard v2

This version provides source-specific typed battery analysis, optional history CSV upload, experimental RUL estimates, validation folds, and a separate collective evidence assessment with a capacity-only second-life screening category.

Run the v2 API and Vite in separate PowerShell windows. From the project root, start the API with `./.venv/Scripts/python.exe -m uvicorn backend.app_v2.main:app --host 127.0.0.1 --port 8001`, then start Vite with `& ./frontend_v2/start-dashboard-v2.cmd`. Vite uses port 5176; the frontend development API URL is `http://127.0.0.1:8001`.

For source-specific analysis, enter the measured SOH reference capacity, previous and current cycle numbers and discharge capacities, and ambient temperature where required. Cycle numbers must increase and capacities must be positive. CSV input remains available as an optional alternative with headers `cycle_number,discharge_capacity_Ah,ambient_temperature_C`. Typed predictions can optionally be saved to the browser-local Prediction log with cell ID, source provenance, and test conditions. Later measurements can be linked to the saved forecast. The log reports exact-target SOH error as a cell-macro MAE by source, distinguishes threshold crossings from right-censored observations, records reviewer-reported second-life assessment outcomes separately, and supports additive JSON import/merge. These user-entered records create a review dataset only; they do not train or alter a model. CSV and collective-assessment results are not yet captured. See [PREDICTION_FOLLOWUP_LOG_v1.md](../PREDICTION_FOLLOWUP_LOG_v1.md) for storage and outcome details, and [MODEL_GOVERNANCE_AND_VALIDATION_ROADMAP_v1.md](../MODEL_GOVERNANCE_AND_VALIDATION_ROADMAP_v1.md) for measured validation limits and the proposed candidate-release gate.

The Collective assessment tab presents evidence from NASA, Oxford, and CALCE comparisons. Because pooled models showed negative transfer in held-out-family evaluation, its typed-input forecast is explicitly a two-point trend baseline rather than a pooled AI result. RUL is withheld in that mode. Second-life output is a low-confidence capacity screen only.

All recommendations are preliminary project heuristics, not safety or certification decisions. RUL is tied to the NASA study's 1.4 Ah cell threshold and has low confidence.
